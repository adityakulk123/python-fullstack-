Tokens

In Python, tokens are the smallest individual units of a program that Python recognizes and understands.

1) identifier 
2) operater 
3) literalas 
4)key words 
5) punctuators


| S.No. | Token Type               | Meaning                                          | Examples                                     |
| ----- | ------------------------ | ------------------------------------------------ | -------------------------------------------- |
| 1     | Keywords                 | Reserved words with special meanings             | `if`, `else`, `for`, `while`, `def`, `class` |
| 2     | Identifiers              | Names given to variables, functions, and classes | `name`, `age`, `calculate_sum`               |
| 3     | Literals                 | Fixed values used in a program                   | `10`, `3.14`, `"Hello"`, `True`              |
| 4     | Operators                | Symbols used to perform operations               | `+`, `-`, `*`, `/`, `==`                     |
| 5     | Delimiters (Punctuators) | Symbols used to structure code                   | `()`, `[]`, `{}`, `:`, `,`                   |


Why Are Tokens Important in Python?
They help Python understand program instructions.
They are the basic building blocks of Python syntax.
They help identify syntax errors.
They are important for learning how Python interprets code.
